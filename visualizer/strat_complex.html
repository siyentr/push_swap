Complex strategy, bit by bit

A replay of sort_complex: an LSD radix sort on each value's rank. One pass per bit, lowest first: every element whose current bit is 1 stays in A (ra), every 0 goes to B (pb), then B is poured back with pa. The strip left of each bar is its rank in binary, most significant bit on the left.

Reading it

Current bit is 1: stays in A, rotated to the bottom.
Current bit is 0: pushed to B. Every row in B shows this color in the current column.
Other set bits. Read a row's strip as binary to get its rank.
B is a stack, so pa returns the zeros in the order they left. After pass k, A is sorted by the low k+1 bits, and the last pass finishes it.
